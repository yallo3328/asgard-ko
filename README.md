# asgard-ko

대만 사설 서버 「日．神之領域」 공식 위키(lizhengqun7-wq.github.io/asgard-website)를 한국어로 보여 주는 탬퍼몽키 스크립트와 번역 사전입니다. 비공식 번역이며, 원문 저작권은 일본판 위키 작성자와 서버 위키 제작자에게 있습니다.

- `asgard_wiki_ko.user.js`: 탬퍼몽키 스크립트
- `ko/`: 페이지별 번역 사전 (중국어 → 한국어)

## MapleLegends 라이브러리 (`ml/`)

메이플레전드 라이브러리(legends.ml/lib)를 한국어로 보여 주는 탬퍼몽키 스크립트와 번역 사전입니다. 비공식 번역입니다.

- `ml/maplelegends_lib_ko.user.js`: 탬퍼몽키 스크립트 (한글·초성 검색 포함)
- `ml/*.json`: 이름 사전 (아이템·몬스터·맵·NPC·퀘스트·스킬, UI 문구, 검색용 ID 목록)
